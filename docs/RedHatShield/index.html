# Zur Beachtung

Das RedHat++ Shield kommuniziert mit DCC-Ex über einen Serial-Port.
Es muss also ein Serial-Port frei sein!

Meinen Test habe ich mit einem Arduino MEGA durchgeführt.
Bei diesem habe ich die Ports 2 und 3 schon belegt:
- Port 2: Bluetooth Stick
- Port 3: integriertes WiFi Modul (8266)

Das RedHat++ Shield kann ohne Änderungen so genutzt werden.
Die Jumper müssen auf die Voreinstellung gesetzt werden.
Dies ist Serial Port 1 des Mega

Da aber auch der USB auf diesem Port liegt, müssen zum Flashen die beiden Jumper entfernt werden!

Zum EX-CSB1 kann ich nichts sagen, da ich dieses nicht nutze!
