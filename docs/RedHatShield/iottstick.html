# Probleme mit dem IoTT Flash Tool unter Linux

  • Benutzerrechte für die Hardware vergeben

    Dein Benutzer braucht Zugriff auf die Gruppe dialout. Ersetze $USER durch deinen Benutzernamen (oder lass es so, Linux setzt deinen Namen automatisch ein):

    sudo usermod -a -G dialout $USER

    Hinweis: Danach einmal aus- und wieder einloggen, damit die Änderung greift!

  • Den "Blockierer" BRLTTY entfernen

    Viele Linux-Systeme (Debian/Ubuntu) installieren den Dienst brltty. Dieser erkennt USB-Serial-Adapter fälschlicherweise als Braille-Display und blockiert sie sofort. Deinstalliere ihn mit:

    sudo apt remove brltty

  • Chromium-Sandbox öffnen (nur für Snap-Nutzer)

    Falls du Chromium als Snap installiert hast (Standard unter Ubuntu), musst du den Zugriff auf USB-Geräte explizit erlauben:

    snap connect chromium:raw-usb

# NTP - Network Time Setup

Die Voreinstellungen sind für die USA eingetragen.
Die Einstellungen für Deutschland mit automatischer Umstellung Normal/Sommerzeit:

  • NTP Server: de.pool.ntp.org
  • Timezone: CET-1CEST,M3.5.0,M10.5.0/3
